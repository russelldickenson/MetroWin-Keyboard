# Privacy

Lumina Keyboard has no analytics, no ads and no trackers, and no account.

| What | Where it goes |
| --- | --- |
| What you type | Nowhere. Not stored, except as the learning below. |
| What the keyboard learns (word counts, which word follows which) | Only the phone's private storage; never learned in password fields or when the app asks for no personalised learning; exportable and erasable in *Settings → Suggestions*. |
| Clipboard history (text, pictures) | Only the phone's private storage; not recorded from password fields or items marked sensitive; the limit is yours. |
| Voice typing | Handled by the speech recogniser of your phone (which may use the internet unless you set "On this phone only"); the keyboard receives text only. |
| Smart correction | Runs on the phone. It uses where you tapped only while the word is being typed and keeps nothing of it; what it keeps, in the same private file as the learned words, are the corrections you undid. Erased with the learned words in *Settings → Suggestions*. |
| Calibration | The taps of the calibration sentences are used on the phone to compute a touch correction (a few numbers) and are then discarded. Only those numbers are stored, in the private storage; *Settings → Size and layout* removes them. |
| Snippets | The shortcuts and texts you make, only in the phone's private storage (and in your backup file if you make one). Never sent anywhere. |
| Backup | A file you make yourself and store where you choose; it holds your settings, learned words and clipboard. The app never sends it anywhere. |

Backups and device transfer are switched off for all of the app's data.
